# FIFA World Cup — прогноз выхода сборных в четвертьфинал

Портфолио-проект по классификации и ранжированию футбольных сборных перед чемпионатом мира. Перенесён из [StatPrac](https://github.com/venfun77/statprak-rovenskiy/blob/main/%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D0%B8%D0%BA%20%281%29.ipynb) в самостоятельную структуру для дальнейшей публикации.

## Постановка задачи

На основе предтурнирных данных (рейтинг FIFA, результаты за последние четыре года, рыночная стоимость состава, страна-хозяйка, континент) предсказать, какая сборная дойдёт до 1/4 финала ЧМ.

Таргет: `quarter_finalist` (1 — вышла в четвертьфинал, 0 — не вышла).

## Данные и валидация

- Источник: [FIFA World Cup Team Dataset на Kaggle](https://www.kaggle.com/datasets/harrachimustapha/fifa-world-cup-team-dataset) (загружается через `kagglehub`).
- Историческая выборка: 192 команды-турнира, по 32 на чемпионатах мира 2002–2022.
- Обучение: 2002–2018; валидация: **2022 год (32 команды)**. Это временное, а не случайное разбиение.
- Прогноз на 2026: после сравнения моделей Random Forest обучен на 2002–2022 и применён к предтурнирным данным 2026 года.
- Итоговые результаты ЧМ-2026 **не включены** в исходный ноутбук; если проводить посттурнирную проверку, её необходимо оформить и датировать отдельно.

## Модели и результаты на ЧМ-2022

| Модель | ROC-AUC | Precision | Recall | F1 | Попадания в топ-8 |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 0.818 | 0.353 | 0.750 | 0.480 | 5/8 |
| Random Forest | **0.906** | **0.545** | **0.750** | **0.632** | **5/8** |

Метрики Precision, Recall и F1 рассчитаны для порога классификации 0,5; топ-8 — отдельная задача ранжирования вероятностей. Данные всего одного турнира (32 наблюдения) дают большую неопределённость. Хороший ROC-AUC сам по себе **не означает**, что модель устойчиво превосходит простые прогнозы фаворитов по рейтингу FIFA.

## Запуск

1. Открыть ноутбук в Google Colab.
2. Установить зависимости при необходимости: `pip install -r requirements.txt`.
3. Запустить ячейки по порядку. Первые ячейки скачивают исходный датасет через `kagglehub`.

При переносе из `statprak-rovenskiy` исправлены две ошибки порядка выполнения: импорт `os` и объявление `target` до первого использования. Результаты, сохранённые внутри ноутбука, получены в предыдущем запуске; обновлённый ноутбук после переноса пока **не перезапускался**.
